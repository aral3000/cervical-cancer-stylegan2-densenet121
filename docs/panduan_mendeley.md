## 🛠️ Langkah-Langkah Pengaturan Mendeley

### Langkah 1: Persiapan Aplikasi & Add-in Microsoft Word
1. Pastikan Anda telah mengunduh dan memasang **Mendeley Reference Manager** di komputer Anda.
2. Pasang ekstensi **Mendeley Cite** untuk Microsoft Word:
   * Buka Microsoft Word.
   * Pilih tab **Insert** -> **Get Add-ins** (atau **Store**).
   * Cari `Mendeley Cite`, lalu klik **Add** untuk memasangnya.
   * Add-in tersebut akan muncul di tab **References** di sebelah paling kanan dengan nama **Mendeley Cite**.

### Langkah 2: Mengimpor Jurnal ke Mendeley Reference Manager
Mendeley memiliki fitur pengekstraksi metadata otomatis yang sangat andal. Anda tidak perlu mengetik detail jurnal satu per satu secara manual.
1. Buka aplikasi **Mendeley Reference Manager** di komputer Anda dan masuk menggunakan akun Mendeley Anda.
2. Buka Windows Explorer dan arahkan ke folder:
   `c:\new era code\GAN_Kompre\Penulisan_Skripsi\Referensi_Jurnal`
3. Pilih **7 berkas PDF** yang tercantum dalam tabel pemetaan di atas.
4. **Tarik dan lepas (Drag & Drop)** ketujuh file PDF tersebut ke halaman tengah aplikasi Mendeley.
5. Mendeley akan membaca metadata berkas PDF secara otomatis untuk mengisi kolom Judul, Penulis, Jurnal, Tahun Terbit, dan Volume/Halaman.

### Langkah 3: Verifikasi Metadata di Mendeley
Terkadang, dokumen PDF tertentu memiliki format metadata yang kurang rapi. Lakukan pemeriksaan berikut:
1. Klik salah satu jurnal yang baru diimpor di Mendeley.
2. Panel detail di sisi kanan akan terbuka. Periksa apakah kolom **Title**, **Authors**, **Journal/Source**, dan **Year** sudah terisi dengan benar sesuai tabel di atas.
3. Jika terdapat kesalahan pembacaan (misalnya penulis tertukar atau nama jurnal kosong), Anda dapat mengeklik kolom tersebut dan memperbaikinya secara langsung pada panel kanan tersebut.

### Langkah 4: Memasukkan Sitasi di Microsoft Word
1. Buka dokumen Word skripsi Anda (`KOMPRE KITA GESS.docx`).
2. Arahkan ke Bab I (Latar Belakang).
3. Klik tab **References** di Word, lalu klik **Mendeley Cite** untuk membuka panel Mendeley di sebelah kanan Word. Masuk menggunakan akun Mendeley Anda jika diminta.
4. Tentukan gaya sitasi terlebih dahulu:
   * Pada panel Mendeley Cite, klik tab **Citation Settings**.
   * Klik **Change citation style**.
   * Pilih gaya **IEEE** (atau **Vancouver**) karena gaya ini menggunakan format angka berurutan di dalam tanda kurung siku seperti `[1]`, `[2]`, dan seterusnya. Klik **Update citation style**.
5. Untuk memasukkan sitasi pertama `[1]`:
   * Letakkan kursor Word tepat sebelum angka `[1]` manual yang ada di paragraf pertama latar belakang Anda.
   * Pada panel Mendeley Cite (tab **References**), cari jurnal Wu (2025) dengan mengetik kata kunci `"GLOBOCAN"` atau `"Jie Wu"` di kolom pencarian.
   * Centang kotak di samping jurnal tersebut, lalu klik tombol **Insert 1 Citation**.
   * Hapus angka kurung siku `[1]` manual Anda, sehingga sekarang posisinya digantikan oleh sitasi dinamis dari Mendeley.
6. Ulangi proses ini secara berurutan untuk sitasi **[2]** sampai **[7]** pada bagian teks Latar Belakang lainnya.

### Langkah 5: Membuat Daftar Pustaka Otomatis
Setelah semua sitasi dinamis terpasang di dalam teks Bab I, Anda dapat membuat Daftar Pustaka otomatis di bagian akhir dokumen:
1. Gulir halaman Word Anda ke bagian paling bawah dokumen (di bawah judul **DAFTAR PUSTAKA**).
2. Letakkan kursor di posisi Anda ingin daftar referensi ditampilkan.
3. Pada panel **Mendeley Cite** di sebelah kanan Word, klik ikon titik tiga (**More** / `...`) di sudut kanan atas panel.
4. Pilih opsi **Insert Bibliography**.
5. Klik **Continue**. Mendeley akan otomatis memformat dan menampilkan daftar pustaka yang rapi dari indeks `[1]` sampai `[7]` sesuai urutan kemunculannya di teks.

---

> [!TIP]
> **Sinkronisasi Otomatis:**  
> Jika Anda mengedit metadata jurnal di aplikasi Mendeley desktop (misalnya mengubah ejaan nama penulis), Anda cukup mengeklik tombol **Refresh References** (ikon putar) di panel Mendeley Cite Microsoft Word untuk memperbarui seluruh sitasi dan daftar pustaka di Word secara otomatis.
